# CarDekho Used Cars — EDA

This repository contains a cleaned Jupyter Notebook for exploratory analysis of used car listings.

Files:
- `20251115_CarDekho_EDA_clean.ipynb` (cleaned notebook)
- `20251115_CarDekho_Dataset.csv` (dataset)

How to run:
1. Clone repository
2. Install dependencies: see requirements.txt
3. Open the notebook and run cells top-to-bottom

Key improvements:
- Standardized header, intro, and problem statement
- Centralized plotting style and helper formatter
- Removed in-notebook pip installs and redundant cells
